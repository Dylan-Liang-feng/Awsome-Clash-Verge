# Clash Verge AI

**Clash Verge AI 让你用一句话指定 Windows 电脑上的哪些网站或软件走代理，哪些直接联网。** 它基于 Clash Verge Rev 2.5.10 开发。Clash Verge 原本就能按规则为不同连接选择线路，但自己添加规则时，往往要先查网站的域名、找软件的进程名，再决定怎样匹配。这个版本把查找和写规则的步骤交给客户端，让你用熟悉的软件名、网站名表达需求。

比如，你平时开着代理，希望 **QQ 邮箱直接联网，Gemini 网页通过代理访问**。在规则编辑器输入「让 QQ 邮箱网页直连，Gemini 网页走代理」，选好要用的代理组。AI 会把这句话拆成两个目标，客户端核对相应域名，并列出每条规则对应的网站和线路。你检查后点「保存」，以后访问这些网站时就会按规则选择线路，省去来回切换代理的操作。

同样，你也可以说「让电脑上的微信直连」。客户端会在本机查找对应程序，供你核对。使用代理线路需要自己的代理节点或订阅，使用自然语言生成规则需要配置自己的模型 API。

本项目基于 Clash Verge Rev，由 [@Dylan-Liang-feng](https://github.com/Dylan-Liang-feng) 开发和维护 AI 规则助手版本。

## 第一次启动

1. 在 v0.1.1 预发行页下载 **Clash-Verge-AI-0.1.1-windows-x64-setup.exe**，双击安装。已在使用原版的用户，先从托盘退出 Clash Verge。
2. 安装包自带内核、规则数据和 Windows x64 WebView2 离线安装程序。可在运行前用 `Get-FileHash` 核对 Release 中的 SHA256SUMS.txt。
3. 打开桌面上的 **Clash Verge AI**。首次使用请导入自己的订阅；需要整机接管时选择「规则」并启用虚拟网卡，按提示授权。日常版与原版共享配置和系统服务，两套客户端轮流运行。
4. 在「订阅」右键目标订阅，打开「编辑规则 → 模型 API 设置」，填写自己的 API 地址、模型 ID 和密钥。生成规则后先核对预览，再保存。导入在线订阅和调用外部模型需要联网。

本次预发行等待全新 Windows 电脑上的离线安装、原版共存及 TUN 授权实测。首次测试可先断网、打开首页，再导入本地合成的 DIRECT 配置；恢复网络后试用自己的订阅。卸载 AI 版后，共享配置和 ProgramData 中的共享服务保留。

## 规则示例

| 输入 | 预览时关注 |
| --- | --- |
| 让我的 QQ 邮箱网页直连 | 只给邮件服务入口加规则，检查有没有误选整个共享父域 |
| 让电脑上的微信走直连 | 检查匹配到的本机程序。如果有多个安装版本，可以选择目标 |
| 某大学官网和它的子域名走代理 | 核对官网来源、匹配后缀和所选代理组 |
| 只让浏览器访问某网站时完全绕过 TUN | 需要按使用指南启用专用系统 PAC，并使用遵循它的浏览器 |

普通 `DIRECT` 规则改变 Mihomo 的出站。已被 TUN 捕获的连接仍会出现在连接页。指定网页通过物理网卡出站另有 Windows 浏览器 PAC 模式，其适用条件见[操作说明](docs/guide.md)。
