## v0.1.1 · Windows x64 离线安装预发行版

**为什么发布这个版本。** v0.1.0 的启动脚本会优先从已安装的原版复制运行组件。如果电脑没有匹配的原版，脚本就需要调用 7-Zip 解压上游安装包；找不到 7-Zip 时，客户端还没打开就会报错。即使组件准备齐全，缺少 WebView2 的电脑也无法正常显示界面。

### 安装和使用有什么变化

- **一个安装文件即可准备运行环境。** 安装包内置稳定版和 Alpha 版 Mihomo 内核、Windows 服务工具、初始规则数据和微软签名的 WebView2 x64 离线安装程序。已装有 WebView2 的电脑会复用现有运行时。导入在线订阅和调用外部模型仍需要联网。
- **原版与 AI 版可以分别启动和卸载。** AI 版有独立安装目录、桌面快捷方式和卸载项。安装前先从托盘退出正在运行的客户端。两版沿用同一套日常配置和系统服务，切换时请先退出当前版本。卸载 AI 版会保留共享配置及 ProgramData 中的共享服务。
- **初始规则数据调整。** 国家和 ASN 数据采用 DB-IP Lite，IP 与域名规则数据采用 v2fly。依赖特定发行方扩展分类的订阅，需要核对它指定的数据源。此安装包省略了再分发许可尚未确认的可选 UWP 回环工具，设置页中也移除了对应入口。[组件版本、来源与许可证](../THIRD_PARTY.md)

**从 v0.1.0 切换。** 从托盘退出 ZIP 版，运行 v0.1.1 安装程序，再从新的桌面快捷方式启动。使用日常版配置的用户可在「订阅」中核对已有订阅和规则。首次使用者请导入自己的订阅；需要 AI 生成规则时，再到「编辑规则 → 模型 API 设置」填写自己的接口。

### 如何核验下载，哪些测试已完成

从本版发布页下载 `Clash-Verge-AI-0.1.1-windows-x64-setup.exe` 和 `SHA256SUMS.txt`。在下载目录打开 PowerShell，执行下面的命令，把输出的 Hash 与校验文件中的值对照。外层安装程序和客户端未做代码签名。

```powershell
Get-FileHash .\Clash-Verge-AI-0.1.1-windows-x64-setup.exe -Algorithm SHA256
```

## v0.1.0 · 自然语言规则助手首次公开发布

- **从一句话生成多条规则。** 例如输入「QQ 邮箱网页直连，Gemini 网页走代理」，模型分别识别目标和线路。用户在编辑器核对候选规则，保存后才写入所选订阅。模型通过用户配置的 Chat Completions 兼容 API 调用，Windows 使用凭据管理器保存接口密钥。
- **用日常名称查找实际目标。** 桌面软件通过快捷方式、运行进程和文件信息匹配；网站通过公开目录或官网资料核对域名。用户可以选择是否加入登录、图片等附加资源，并在有多个候选时确认范围。
- **区分直连与绕过 TUN。** 普通直连规则指定流量进入 Mihomo 后的出站方式。对遵循 Windows 系统 PAC 的浏览器，本版还支持将指定网站交给绑定物理网卡的本机出口，其他请求继续按系统路由进入 TUN。这项功能需要单独配置。[配置步骤与适用条件](guide.md)
- **首次发布采用 ZIP。** 两条组件准备路径均做过验证：从已有原版安装目录复制，或用 7-Zip 解压固定版本的上游安装包。发布时前端的 64 项测试通过。

关于小型本地模型为何改为 API、怎样处理软件别名和域名范围，以及如何验证实际出站路径，见[开发过程与经验](development-journey.md)。
